## How WebSockets Work in This ChatBot System

WebSockets enable **real-time, bidirectional communication** between clients (customers/agents) and the server. Here's how they work in your system:

---

### **1. WebSocket Architecture**

```
Customer Browser ←→ WebSocket Server (Port 8080) ←→ Agent Dashboard
                           ↓
                    AWS Bedrock AI
```

**Key Components:**
- **Server**: Python WebSocket server (`chatbot_server.py`) on port 8080
- **Clients**: React customer chat + Agent dashboard (both connect via WebSocket)
- **Protocol**: Persistent TCP connection (not HTTP request/response)

---

### **2. Connection Lifecycle**

#### **Customer Connection Flow:**

```javascript

  console.log('Connected to WebSocket');

  const data = JSON.parse(event.data);
  // Handle incoming messages from server

```

#### **Agent Connection Flow:**


#### **Server Handler:**

```python
async def handler(websocket):
    """Main handler - one instance per connection"""
    session_id = None  # For customers
    agent_id = None    # For agents
    
    try:
        # Listen continuously for messages
        async for message in websocket:
            data = json.loads(message)
            # Route based on message type
            if data.get("type") == "agent_connect":
                agent_id = await handle_agent_connect(websocket, data)
            elif data.get("type") == "user_message":
                await handle_user_message(session_id, websocket, data)
```

### **Key Advantages of WebSockets Here:**

1. **Persistent Connection**: No repeated HTTP handshakes
2. **Bidirectional**: Server can push messages to clients instantly
3. **Low Latency**: Real-time queue updates, instant message delivery
4. **Efficient**: Single connection handles all communication
5. **Stateful**: Server maintains session context throughout conversation

This architecture enables seamless real-time chat between customers, AI, and human agents with instant routing and queue management.

## WebSocket is in **BOTH** Frontend and Backend

Here's the simple breakdown:

---

### **Backend (Server Side)**
```python
# Python WebSocket Server - chatbot_server.py
import websockets

async def handler(websocket):
    # Server listens for connections
    async for message in websocket:
        # Receive and process messages
        await websocket.send("response")  # Send back

# Start server on port 8080
async def main():
    async with websockets.serve(handler, "localhost", 8080):
        await asyncio.Future()
```

**Role**: 
- Listens on `ws://localhost:8080`
- Accepts connections from clients
- Routes messages between customers and agents

```
┌─────────────────┐                    ┌─────────────────┐
```

- **Frontend** = Guest (initiates connection)

#### **3. Message Routing Logic**
```python
async def handle_user_message(session_id, websocket, data):
    user_message = data.get("message")  # "Hello"
    
    # Save to history
    user_sessions[session_id]["history"].append({
        "sender": "user", 
        "message": user_message
    })
    
    # ═══════════════════════════════════════════════════
    # SCENARIO A: User is connected to AGENT
    # ═══════════════════════════════════════════════════
    if user_sessions[session_id].get("paired_agent"):
        paired_agent = user_sessions[session_id]["paired_agent"]
        
        # Forward message to agent's WebSocket
        await all_agents[paired_agent].send(json.dumps({
            "type": "user_message",
            "sessionId": session_id,
            "message": user_message
        }))
        
        # Send acknowledgment to user
        await websocket.send(json.dumps({"type": "agent_ack"}))
        return  # DONE
    
    # ═══════════════════════════════════════════════════
    # SCENARIO B: User is in QUEUE
    # ═══════════════════════════════════════════════════
    if session_id in user_queue:
        position = user_queue.index(session_id) + 1
        await websocket.send(json.dumps({
            "type": "response",
            "message": f"You are #{position} in queue. Please wait..."
        }))
        return  # DONE
    
    # ═══════════════════════════════════════════════════
    # SCENARIO C: New message - Check INTENT
    # ═══════════════════════════════════════════════════
    intent = detect_intent(user_message)
    
    if intent == "human_agent":
        # User wants human agent
        user_queue.append(session_id)
        position = len(user_queue)
        
        await websocket.send(json.dumps({
            "type": "response",
            "message": f"You are #{position} in queue. Agent will connect shortly..."
        }))
        
        # Notify all agents
        await broadcast_stats()
    else:
        # AI handles the message
        response = handle_intent(intent, user_message, session_id)
        await websocket.send(json.dumps(response))
```

```python
def detect_intent(message):
    human_keywords = ["human", "agent", "representative", "support"]
    
    if any(keyword in message.lower() for keyword in human_keywords):
        return "human_agent"
    
    return "bedrock"  # AI handles it
```
